Authentication Flow

Step-by-step walkthrough of how login, route protection, and logout work.

Login Flow

1
User visits /super-admin/login
Route is inside middleware('guest') group — logged-in users are redirected away. Loads the App\Livewire\Auth\Login component wrapped in components.layouts.auth.
2
User submits form → wire:submit="login"
Livewire calls Login::login(). Fields are validated with #[Validate] attributes first. Then a rate-limiter key (email|ip) is checked — max 5 attempts before lockout.
3
Auth::attempt() is called
If credentials fail → RateLimiter::hit(), error message set, password cleared.
If credentials pass → move to step 4.
4
Role is verified
auth()->user()->hasRole('super_admin') is checked. If not super_admin → Auth::logout() immediately, error displayed. This prevents business_owner/staff from accessing the super admin panel even with valid credentials.
5
Session regenerated → redirect to dashboard
RateLimiter::clear(), session()->regenerate(), then $this->redirect(route('super-admin.dashboard'), navigate: true). The navigate: true flag uses Livewire's SPA navigation (no full page reload).

Route Protection Flow

1
Request hits a protected route
e.g. GET /super-admin/dashboard — middleware stack: ['auth', 'super_admin']
2
Laravel's built-in auth middleware runs
Is the user logged in? If not → redirect to super-admin.login.
3
SuperAdminMiddleware runs
Calls auth()->user()->hasRole('super_admin'). If false → abort(403). The alias 'super_admin' is registered in bootstrap/app.php.
4
UpdateLastLogin middleware runs (on every web request)
Calls auth()->user()->updateQuietly(['last_login_at' => now()]) silently — no events fired, no timestamps updated.

Key Files

FileResponsibility
app/Livewire/Auth/Login.phpRate-limiting, credential check, role guard, session regen
app/Http/Middleware/SuperAdminMiddleware.phpRoute-level role check → abort(403) or pass through
app/Http/Middleware/UpdateLastLogin.phpStamps last_login_at quietly on every authenticated request
bootstrap/app.phpRegisters 'super_admin' alias + appends UpdateLastLogin to web group
routes/web.phpDefines middleware groups around route groups

Logout Flow

phpapp/Livewire/Auth/Logout.php
public function logout(): void
{
    Auth::logout();              // Clear auth state
    session()->invalidate();    // Destroy the session
    session()->regenerateToken(); // New CSRF token
    $this->redirect(route('super-admin.login'), navigate: true);
}

The logout is triggered by the <form method="POST"> inside header.blade.php. It POSTs to /super-admin/logout which maps to this component.

// Check role
auth()->user()->hasRole('super_admin');   // returns bool
auth()->user()->isSuperAdmin();           // helper on User model

auth()->user()->can('business.create');

// Assign a role
$user->assignRole('manager');

Routes

// Root redirect
Route::get('/', fn() => redirect()->route('super-admin.dashboard'));

Route::prefix('super-admin')->name('super-admin.')->group(function () {

    // Guest only (redirect if already logged in)
    Route::middleware('guest')->group(function () {
        Route::get('/login', Login::class)->name('login');
    });

    // Auth + super_admin role required
    Route::middleware(['auth', 'super_admin'])->group(function () {
        Route::get('/dashboard',         DashboardPage::class)->name('dashboard');

    // Logout (POST, auth only)

});

Middleware

phpbootstrap/app.php — where middleware is registered
->withMiddleware(function (Middleware $middleware): void {

    // 1. Register named alias so routes can use 'super_admin'
    $middleware->alias([
        'super_admin' => SuperAdminMiddleware::class,
    ]);

    // 2. Append UpdateLastLogin to every web request automatically
    $middleware->appendToGroup('web', [
        UpdateLastLogin::class,
    ]);
})
phpapp/Http/Middleware/SuperAdminMiddleware.php
public function handle(Request $request, Closure $next): Response
{
    if (!auth()->check()) {
        return redirect()->route('super-admin.login');
    }

    if (!auth()->user()->hasRole('super_admin')) {
        abort(403, 'Super Admin privileges required.');
    }

    return $next($request);
}
Tip: Adding new middleware

To add a new middleware to admin routes only, create the class in app/Http/Middleware/, register an alias in bootstrap/app.php, then add it to the route group in routes/web.php.
